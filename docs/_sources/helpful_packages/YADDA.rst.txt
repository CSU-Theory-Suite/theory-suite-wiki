=====
YADDA
=====

``YADDA``, or Yet Another Distortion-interaction Decomposition Automation is a 
package developed by the Paton group which helps in the automation of 
distortion-interaction analysis along an IRC, as well as energy decomposition analysis.

`YADDA Documentation and GitHub Page <https://github.com/patonlab/yadda/tree/main>`_.

`Sample End-to-End YADDA Workflow <https://csu-theory-suite.github.io/theory-suite-wiki/running_calculations/example_yadda_workflow/example_yadda_workflow.html>`__
